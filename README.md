# 如何添加新的 SN 码

本文说明如何在 GitHub 上为 SN 查询网站添加、修改产品料号。

**你只需要修改一个文件：** `data/products.json`

**网站地址：** https://sn.zephyrsz.com（GitHub Pages 自动发布，提交后约 1～2 分钟生效）

> 网站直接读取 `products.json`，提交后无需其他操作。

---

## 第一步：打开文件

1. 登录 GitHub
2. 进入本仓库
3. 打开 `data/products.json`
4. 点击右上角 **铅笔图标**（Edit）

---

## 第二步：判断放进哪个数组

打开 `products.json` 后，文件里有三个数组，根据 SN 类型选择：

| 数组 | 适用情况 | 示例料号 |
|------|----------|----------|
| `newRules` | **新款 SN**（2025 年后，一般以 `Z` 开头） | `Z5701G`、`Z3602S` |
| `oldRules` | **旧款 SN**（以 `ZF`、`LH` 等开头） | `ZF3601`、`LH360223` |
| `exceptions` | **特例 SN**（某一条 SN 需要固定显示，不能自动解析） | 完整 SN 如 `LH3602231120000019` |

> 不确定时，看 SN 贴纸上的前缀，与现有条目对比，放进相同类型的数组即可。

---

## 第三步：复制模板并填写

### 情况 A：添加新款 SN → `newRules`

在 `newRules` 数组的 **最后一项后面** 添加（注意上一行末尾加逗号）：

```json
    ,
    {
      "prefix": "Z5801G",
      "model": "ZEPHYR RTX 5080 16G 深渊"
    }
```

| 字段 | 填什么 |
|------|--------|
| `prefix` | SN 开头的料号，必须与真实 SN **完全一致**（区分大小写） |
| `model` | 用户查询时显示的**产品型号全称** |

---

### 情况 B：添加旧款 SN → `oldRules`

在 `oldRules` 数组末尾添加：

```json
    ,
    {
      "prefix": "ZF5801",
      "model": "ZEPHYR RTX 5080 16G 浪花"
    }
```

字段含义与 `newRules` 相同。

---

### 情况 C：添加特例 SN → `exceptions`

当某条 SN 无法按通用规则解析，需要**固定显示**型号和出厂日期时使用。

在 `exceptions` 数组末尾添加：

```json
    ,
    {
      "sn": "LH3602231120000019",
      "model": "浪花RTX3060 12G",
      "dateText": "2024年第42周"
    }
```

| 字段 | 填什么 |
|------|--------|
| `sn` | **完整序列号**，一字不差，不能有空格 |
| `model` | 显示的产品型号 |
| `dateText` | 显示的出厂日期，如 `2024年第42周` 或 `2024-10-15` |

---

## 第四步：检查格式

提交前确认：

- [ ] 每个 `{` 都有对应的 `}`
- [ ] 每个 `{ ... }` 之间用 **英文逗号** `,` 分隔
- [ ] **最后一个** `{ ... }` 后面 **不要** 加逗号
- [ ] 所有文字用 **英文双引号** `"` 包裹
- [ ] `prefix` / `sn` 没有多余空格
- [ ] 没有重复添加相同的 `prefix` 或 `sn`

---

## 第五步：提交

1. 滚到页面底部 **Commit changes**
2. 填写说明，例如：`新增 Z5801G 料号`
3. 点击 **Commit changes**
4. 等待 1～2 分钟，打开 https://sn.zephyrsz.com 测试

---

## 完整示例

假设要新增料号 `Z5801G`，产品型号 `ZEPHYR RTX 5080 16G 深渊`：

**修改前**（`newRules` 末尾）：

```json
    {
      "prefix": "ZV7605",
      "model": "ZEPHYR RX 7600 8G 风神 MT"
    }
  ],
```

**修改后**：

```json
    {
      "prefix": "ZV7605",
      "model": "ZEPHYR RX 7600 8G 风神 MT"
    },
    {
      "prefix": "Z5801G",
      "model": "ZEPHYR RTX 5080 16G 深渊"
    }
  ],
```

---

## 修改已有料号

1. 在文件中按 `Ctrl+F` 搜索 `prefix` 或产品型号
2. 只修改 `"model"` 的值
3. 一般 **不要改** `prefix`（除非料号规则本身变更）

---

## 删除料号

找到对应的整个 `{ ... }` 块删除，并检查前后逗号是否正确。

---

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| GitHub 提交后显示红色 ❌ | JSON 格式错误 | 检查逗号、引号；参考 `_meta` 中的说明 |
| 网站查不到新型号 | 放错数组或 prefix 写错 | 核对 SN 前缀，确认在正确数组 |
| 特例 SN 不生效 | `sn` 与真实 SN 不完全一致 | 重新复制完整 SN |
| 网站提示无法加载数据 | JSON 语法错误导致文件无法解析 | 用 History 恢复上一版本 |

---

## 改错了怎么办

1. 打开 `data/products.json`
2. 点击 **History**
3. 找到修改前的版本
4. 复制旧内容重新提交，或点击 **Revert**

---

## 不要修改的内容

| 文件/字段 | 说明 |
|-----------|------|
| `_meta` | 文件顶部的说明信息，不要删除 |
| `index.html`、`js/` | 程序代码，由开发人员维护 |
| `CNAME`、`.nojekyll` | GitHub Pages 配置 |

如有疑问，请联系仓库管理员。

---

## 开发人员本地测试

浏览器不允许在 `file://` 下加载 `data/products.json`，本地请启动 HTTP 服务：

```bash
python -m http.server 8080
```

Windows 也可双击 `serve.bat`，然后访问 http://localhost:8080
